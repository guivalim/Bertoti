3. 3 exemplos de tradeoffs

Engenharia de software está ligada com o ato de programar, entretanto temos algo que a diferencia da programação. Assim como outras engenharias ela envolve planejamento estratégico, então a programação anda junto com métodos de planejamentos.

Os processos se juntam com o ato de escrever códigos quando a engenharia visa o "futuro", planejando fatos que estarão por vir, como a aplicação se comportará diante de diferentes situações, podemos citar sobre a escalabilidade de um software. Um certo programa funciona com x quantidade de usuários, mas com x ao cubo de usuários, ele funciona com a mesma qualidade ou ao menos funciona? A engenharia de Software visa planejar o andamento dos códigos ao longo de sua vida.

Trade off (conceito): O que são Trade-Offs no Aprendizado de Máquina? Um trade-off descreve uma situação na qual você sacrifica uma coisa para alcançar outra. No universo do Aprendizado de Máquina, isso representa a necessidade de encontrar um equilíbrio entre duas características que não podem ser maximizadas simultaneamente.
Exemplos: Tempo de Desenvolvimento vs Qualidade do Código; Segurança vs Usabilidade; Desenvolvimento Próprio vs Uso de Bibliotecas de Terceiros
